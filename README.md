# gold-investment-app

市場データはバックエンドのプロセス内で1時間キャッシュします。
GLDは1年分をまとめて取得し、最新価格と全チャート期間で共有します。
通常のダッシュボード表示で外部APIを呼ぶのは、キャッシュがない場合の
Twelve Data 2回（GLD・USD/JPY）とGold API 1回です。
1時間以内の再表示・期間切り替えでは追加取得しません。
期限後のアクセス時に更新し、定期的な自動取得は行いません。
外部APIのエラー時はサービスごとに1時間取得を休止し、503を返します。
数値のRetry-Afterが1時間より長い場合は、その時間を待ちます。
キャッシュは再起動で消え、複数ワーカープロセス間では共有されません。

フロントエンドは同一URLへの通信中のGETを共有し、StrictModeのEffect再実行による
重複通信を抑えます。通信完了後の結果は保持せず、キャッシュはバックエンドで管理します。
期間切り替え・アンマウント後に届いた古い結果は画面に反映しません。
取得失敗時はAPIが返す日本語の理由を表示し、接続できない場合も専用のメッセージを表示します。

テスト（外部APIへの通信なし）:
- frontend: Node.js 24で `npm test`（通信の重複・エラー処理のモックテスト）
- backend: `python -m unittest discover -v`
